## 🚀 Overview
**TWIN DRIVE** is a secure, end-to-end Industrial IoT (IIoT), edge AI machine vision, behavioral digital twin, and predictive maintenance platform built for next-generation electric mobility and aerospace systems. The platform simulates smart manufacturing assembly lines, quality assurance gates, and live vehicular operational physics across five synchronized industry configurations.

## ⚙️ Core Architecture & Modules
1. **Factory Automation**: Event-driven 4-stage PLC finite state machine (Infeed ➔ Process ➔ AOI Gate ➔ Outfeed) with cycle-time tracking and E-Stop interlocking.
2. **Machine Vision**: Real-time edge optical inspection on HTML5 Canvas emulating YOLOv8 object detection, defect classification, and automated rejection gating.
3. **Digital Twin**: High-fidelity 3D WebGL (Three.js) CAD simulation inside an electric holographic blue viewport, featuring procedural kinematics and 3 isolated sensor streams per vehicle.
4. **Predictive Maintenance**: XGBoost/LSTM prognostics engine calculating dynamic Remaining Useful Life (RUL), MTBF, and automated maintenance ticketing based on thermal, vibrational, and electrical stress models.

4. Click **"ENTER SYSTEM CONSOLE"** and authenticate using developer credentials.
